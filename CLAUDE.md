## Direction artistique

### Illustrations
- Les traits des maquettes ne sont que des sketchs. Les illustrations finales sont **en aplats avec des dégradés doux** pour donner un faux volume, sans contour, avec un **grain** par-dessus.
- Ref aimée : affiche « Bonne rentrée les potes » (palette saturée orange/rose/violet/bleu/vert/jaune sur fond lavande, proportions exagérées, grain, serif ronde grasse dans les coins).
- Personnages : Léa (carré à frange, boucle d'oreille, joues roses) et Maël (cheveux bouclés, barbe), à une table avec des ordinateurs au **logo poire**, pouce levé.
- Autres refs (illustrateurs, sites, affiches) : `À REMPLIR`

### Couleurs
- Vues dans la maquette : blanc, noir, vert citron (bande Services), rouge confiture.
- Palette fixée ou à pousser vers celle de la ref ? `À REMPLIR`
- Codes couleurs existants : #7D3522, #DC472E, #ECB552, #E79DBF, #FDF0E2, #579E6D, #3C86BD, #A2D1D4

### Typographie
- Maquette : grosse linéale grasse en capitales. Ref : serif ronde grasse.
- Choix (linéale, serif, mélange ?) et noms des polices : Titres : Faro , Courant : Geist
- Licences web OK ? `À REMPLIR`

### 3D
- On mélange faux volume (illustrations) et vraie 3D rendue dans le même style : dégradés doux, grain, pas de photoréalisme.
- Moment fort : une **tartine 3D qui descend la page au scroll** et se pose à l'endroit sur le footer, sur la table de Léa et Maël.
- Modèle 3D : tartine modélisée en code dans three.js (`explorations/tartine3d.js`), remplaçable plus tard par un GLB Blender.
- Autres objets en 3D envisagés : `À REMPLIR`

## Règles pour Claude

- Le Figma n'est pas représentatif, ni dans le style ni dans les layouts. Il sert seulement d'inventaire des contenus. Les layouts sont à réinventer ensemble, page par page.
- Une seule scène 3D forte, le reste en 2D. Toujours respecter `prefers-reduced-motion`.
- Thème clair uniquement. Accessibilité WCAG 2.2 AA, mobile d'abord.
- Agents du projet (dans `.claude/agents/`) : `front-designer`, `ux-designer`, `3d-artist`, `front-developer`, audits avec `ux-ui-reviewer`.
- Agents Agency copiés depuis la banque `~/Projets/agency-agents` : tout Design, l'intégration web (Frontend Developer, CMS Developer, Rapid Prototyper, Senior Developer, Minimal Change Engineer, Code Reviewer, Section 508 Accessibility Specialist) et la sécurité utile à un site vitrine (Application Security Engineer, AI-Generated Code Security Auditor, Security Architect, Secrets & Credential Hygiene Engineer, Privacy Engineer, Compliance Auditor).
